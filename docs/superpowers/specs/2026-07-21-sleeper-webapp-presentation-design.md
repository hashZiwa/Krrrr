# Sleeper 웹앱 발표자료 디자인 명세

## 목적

교수와 심사위원이 Sleeper 웹앱의 역할, 데이터 처리 과정, 분석 기능, 제어 기능, 데이터 및 모델 관리 구조를 짧은 설명만으로 이해하도록 한다.

발표가 끝날 때 청중은 이 웹앱이 단순한 시각화 화면이 아니라 수면 데이터의 수집, 분석, 제어, 저장, 재학습을 연결한 통합 관리 도구라는 점을 이해해야 한다.

## 시각적 기준

- 참고 자료: `C:/Users/jmlee/Downloads/크어어어억_찐최종임(영상미포함).pptx`
- 참고 구간: 13~16페이지를 중심으로 전체 자료의 디자인 규칙을 따른다.
- 흰색 배경, 진한 남색 제목, 상하단의 얇은 파란색 선을 유지한다.
- 실제 웹 화면 캡처를 각 페이지의 중심 시각 자료로 사용한다.
- 보라색 또는 파란색 주석과 화살표로 한 페이지당 2~4개 요소만 강조한다.
- 한 페이지에는 하나의 기능 또는 하나의 설명 목적만 배치한다.
- 원본 슬라이드의 글꼴, 제목 계층, 여백, 페이지 표기와 장식 요소를 보존한다.
- 새 슬라이드는 원본 PPT의 적합한 슬라이드를 복제한 뒤 기존 요소를 편집하는 방식으로 제작한다.

## 내러티브 구조

전체 흐름은 `웹앱의 역할 → 데이터 입력 → 과거 및 실시간 처리 → 분석 결과 → 제어 → 데이터 관리 → 모델 관리 → 통합 순환 구조`로 구성한다.

각 슬라이드는 다음 슬라이드에서 답할 질문을 자연스럽게 만든다. 예를 들어 전체 화면 소개 이후 데이터가 어디서 들어오는지를 설명하고, 입력 방식 이후에는 실제로 어떤 결과가 만들어지는지를 보여준다.

## 슬라이드 구성

### 1. 웹앱 전체 소개

- 핵심 메시지: 수면 데이터의 수집부터 분석과 관리까지 하나의 웹앱으로 통합했다.
- 주요 시각 자료: 웹앱 전체 화면.
- 강조 항목: 데이터 입력, 수면 분석, 알람, 플랫폼 데이터, 모델 관리.

### 2. 웹앱의 데이터 처리 흐름

- 핵심 메시지: CSV와 Mobius 실시간 데이터를 공통 수면 세션으로 변환한다.
- 주요 시각 자료: `데이터 입력 → Node.js 서버 → 정규화 및 추론 → React 화면` 흐름.
- 기존 IoT 리소스 설계와 중복되지 않도록 웹앱 관점의 처리만 설명한다.

### 3. 저장된 수면 데이터 선택

- 핵심 메시지: 측정 기록을 선택하면 해당 세션의 모든 분석 결과가 갱신된다.
- 주요 시각 자료: 관찰 데이터 선택 패널과 선택 후 갱신된 화면.

### 4. 실시간 수면 모니터링

- 핵심 메시지: Mobius의 신규 데이터를 주기적으로 조회해 실시간 세션을 갱신한다.
- 주요 시각 자료: 실시간 시작 버튼, 확인 모달, 모니터링 상태.
- 설명 항목: 학습 모델 확인, 기준 데이터 확인, 30초 단위 갱신.

### 5. 실시간 세션 저장

- 핵심 메시지: 실시간으로 수집한 데이터를 분석 가능한 새 기록으로 저장한다.
- 주요 시각 자료: 종료 및 저장 모달, 저장 완료 상태, 데이터 목록 반영.

### 6. 수면 분석 요약

- 핵심 메시지: 원시 수면 데이터를 무호흡 정도와 수면 깊이 비율로 요약한다.
- 주요 시각 자료: 무호흡 게이지와 수면 단계 도넛 차트.

### 7. 호흡 데이터 시계열 분석

- 핵심 메시지: 호흡 변화가 발생한 시간 구간을 확인할 수 있다.
- 주요 시각 자료: 호흡수 그래프 확대 화면과 대표 변화 구간 강조.

### 8. 수면 단계 변화 분석

- 핵심 메시지: 수면 단계의 전환 시점과 호흡 변화 당시의 수면 상태를 확인한다.
- 주요 시각 자료: 수면 단계 그래프와 공통 시간축 설명.

### 9. 알람 설정 및 상태 관리

- 핵심 메시지: 알람 활성화, 시간, 작동 상태를 웹에서 관리한다.
- 주요 시각 자료: 알람 패널 확대 화면.
- 설명 항목: ON/OFF, 시간 설정, 업로드 상태, 현재 작동 상태.

### 10. 플랫폼 데이터 조회 및 저장

- 핵심 메시지: Mobius 원시 데이터를 날짜별로 묶어 분석 가능한 기록으로 저장한다.
- 주요 시각 자료: 플랫폼 데이터 패널 확대 화면.
- 설명 항목: 데이터 조회, 날짜별 그룹화, 선택 저장, 저장 상태 구분.

### 11. 수면 단계 모델 관리

- 핵심 메시지: 새로운 CSV 데이터로 모델을 전체 재학습하거나 추가 학습할 수 있다.
- 주요 시각 자료: 학습 모델 관리 패널 확대 화면.
- 설명 항목: 모델 상태, 데이터 수, CSV 업로드, 전체 및 추가 학습.

### 12. 기능 통합 및 마무리

- 핵심 메시지: 수집, 분석, 제어, 저장, 학습이 하나의 순환 구조로 연결된다.
- 주요 시각 자료: `데이터 수집 → 분석 → 알람 및 확인 → 저장 → 추가 학습` 순환 흐름.
- 이후 발표 내용과 중복되면 이 슬라이드는 제외할 수 있다.

## 콘텐츠 작성 규칙

- 제목은 기능명이 아니라 해당 페이지의 결론을 전달한다.
- 본문은 최대 2~4개의 짧은 설명으로 제한한다.
- 구현되지 않은 성능, 정확도, 효과를 임의로 주장하지 않는다.
- 분석 지표와 모델 상태는 실제 서비스 화면 또는 코드에서 확인 가능한 내용만 사용한다.
- 발표자용 상세 설명은 화면에 넣지 않고 필요한 경우 발표 노트로 분리한다.

## 제작 및 검증

- 원본 PPTX를 보존하고 별도의 결과 PPTX를 생성한다.
- 원본 슬라이드 전체를 검사한 뒤 각 결과 슬라이드를 적합한 원본 슬라이드에 매핑한다.
- 실제 실행 화면을 캡처해 사용하며 가짜 UI나 재현 이미지를 만들지 않는다.
- 최종 PPTX의 모든 페이지를 PNG로 렌더링해 잘림, 겹침, 글자 줄바꿈, 이미지 크롭을 확인한다.
- 원본의 글꼴과 장식 요소가 유지되었는지 확인한다.
- 필요 시 12번 마무리 슬라이드를 제외한 11페이지 버전으로 조정한다.
